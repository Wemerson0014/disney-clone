# 🎬 Disney+ Clone

Este é um projeto de estudo que replica a interface e as principais funcionalidades do Disney+. O objetivo foi consolidar conhecimentos em React, estilização com Tailwind CSS e integração com Firebase para autenticação e banco de dados.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as melhores práticas e ferramentas modernas de desenvolvimento web:

* **[React](https://reactjs.org/)** - Biblioteca principal para construção da interface.
* **[Vite](https://vitejs.dev/)** - Tooling de próxima geração para um desenvolvimento rápido e otimizado.
* **[Tailwind CSS](https://tailwindcss.com/)** - Framework CSS utilitário para estilização rápida e responsiva.
* **[Firebase](https://firebase.google.com/)** - Utilizado para Autenticação (Google Login) e Firestore (Banco de dados NoSQL).
* **[React Router Dom](https://reactrouter.com/)** - Gerenciamento de rotas e navegação.
* **[Lucide React](https://lucide.dev/) / Icons** - Conjunto de ícones para compor o visual.

---

## ✨ Funcionalidades

- ✅ **Autenticação com Google:** Login seguro utilizando Firebase Auth.
- ✅ **Interface Responsiva:** Adaptada para diferentes tamanhos de tela com Tailwind.
- ✅ **Sliders & Carrosséis:** Exibição dinâmica de destaques e categorias.
- ✅ **Página de Detalhes:** Informações específicas de filmes e séries buscadas do banco de dados.
- ✅ **Proteção de Rotas:** Acesso ao conteúdo apenas para usuários autenticados.

## 🛠️ Como rodar o projeto localmente

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/Wemerson0014/disney-clone.git](https://github.com/Wemerson0014/disney-clone.git)
    ```

2.  **Acesse a pasta do projeto:**
    ```bash
    cd disney-clone
    ```

3.  **Instale as dependências:**
    ```bash
    npm install
    # ou
    yarn install
    ```

4.  **Configure o Firebase:**
    - Crie um arquivo `.env.local` na raiz do projeto.
    - Adicione suas chaves do Firebase (VITE_FIREBASE_API_KEY, etc.).
    - Variáveis de ambiente utilizadas (VITE_FIREBASE_AUTH_DOMAIN, VITE_FIREBASE_PROJECT_ID) 

5.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    # ou
    yarn dev
    ```
